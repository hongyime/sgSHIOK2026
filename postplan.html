Implemented

Two choices, one useful default

MRT/LRT exits and Bus stops only. A new search chooses the shortest usable saved walking route across both; a category click chooses within that category. Explicit saved-walk links retain their chosen stop and variant.

Closest means saved walking distance, not straight-line proximity. It does not mean every nearby stop has been routed. Stable ties and unavailable geometry are tested.

Implemented

No technical dump or comparison controls

SHIOK top left, search beneath, compact equal-width result. Destination and walk measurements first; uncovered sections and saved alternatives in Walk details. No Compare, About data, Technical record or score essay. Data information lives in GitHub README and attribution documentation.

Required basemap attribution remains. Old comparison fragments do not open or load a shortlist; stored data is not deleted.

Implemented

Preview failure cannot erase a saved walk

Reject failed HTTP responses and end a hanging preview after 12 seconds, including its response body. Keep the previous usable saved walk and marker visible. Retry makes one new request; Back restores the saved selection and URL. Ignore late responses.

Root cause found locally: the old QA proxy blocked every API request. The new proxy permits only GET /api/onemap-route. One public live request succeeded through the repaired API (HTTP 200, about 356 ms). This is an observed case, not an all-stop uptime promise. Stops without saved geometry still need a successful online preview.

Implemented

Automatic night lighting

No toggle. Load lamp-post data for the current neighbourhood when sufficiently zoomed in. Optional lamp failures do not block the selected walk. Do not download the entire island or label mapped lamps as a safety rating.
