This routine reads publisher metadata only. It does not download datasets, ingest inputs, score routes, export data, deploy the app, change published maps or store private resident reports.

Operations:
- Standard public-repository GitHub-hosted runner, no paid service or Cloudflare.
- Maximum 24 metadata requests plus 3 batches of 24 notice API requests; 25-minute job cap.
- Immutable 30-day artifacts carry the whole retained monitor and send history, with bounded storage. The newest verified artifact is required for continuity.
- Do not use Re-run jobs. All reruns are rejected because deleted newer history cannot be ruled out. A new manual dispatch is allowed only with an intact ready predecessor, with bootstrap=false.
- Missing, expired, stopped or conflicting history requires investigation. Never delete journals, bootstrap again or automatically resend to repair it.
- GitHub schedules are best effort and can be disabled after public-repository inactivity. Check for a missing weekly run as well as new notices. GitHub delivery failures remain visible in Actions.
